# Project Overview: i-saw-u

## What it does
`i-saw-u` is a Next.js / React application that allows users to upload event/concert photos, inspect their EXIF metadata (capture date, GPS coordinates), and cross-reference that date with concert database show histories (e.g., Phish show dates via Phish.net / Phish.in APIs).

## Current Tech Stack
- Framework: Next.js (App Router), React, Server Components
- Styling: Tailwind CSS
- Data Fetching: Server Actions & standard fetchers

## Upcoming Goals
Phase 1: User Authentication (e.g., NextAuth / Auth.js or Supabase Auth)
Phase 2: Persistent Cloud Storage (e.g., AWS S3, Supabase Storage, or Cloudinary for user photo libraries)
